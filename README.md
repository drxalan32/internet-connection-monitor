# Internet Connection Monitor

A lightweight Python project by **StreamNexa** focused on monitoring internet connectivity and network stability.

## Project Goals

The goal is to build a simple tool that helps users understand the reliability of their internet connection.

Planned features:

- Monitor internet connectivity.
- Measure ping latency.
- Detect packet loss.
- Record connection interruptions.
- Track uptime and downtime.
- Export monitoring results.

## Status

🚧 **Currently in development.**

## Planned Technologies

- Python
- ICMP Ping
- CSV reports
